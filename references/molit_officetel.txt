출처: 국토교통부, 「국토교통부_오피스텔 전월세 실거래가 자료」, 공공데이터포털
원문: https://www.data.go.kr/data/15126475/openapi.do
인용 구분: 아래 내용은 위 자료의 API 설명 원문을 직접 인용한 문구입니다.

“「부동산 거래신고 등에 관한 법률」에 따라 신고된 자료 및 「주택임대차보호법」에 따라 부여된 확정일자 자료로서 행정표준코드관리시스템(www.code.go.kr)의 법정동 코드 중 앞5자리(예시 : 서울 종로구 - 11110), 계약년월 6자리(예시 : 201801)로 해당 지역, 해당 기간의 오피스텔 전월세 실거래가 상세자료를 조회할 수 있습니다. API 설명 : 지역코드와 기간을 설정하여 해당지역, 해당기간의 오피스텔 전월세 자료를 제공하는 오피스텔 전월세 실거래가 상세 자료 조회 * 공개내용 중 개인정보보호를 위해 오피스텔 전월세의 동/호정보는 제공되지 않습니다.”
